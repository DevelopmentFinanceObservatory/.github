# DFO community health files

This repository holds the defaults that apply across the [Development Finance Observatory](https://github.com/DevelopmentFinanceObservatory) organisation on GitHub, and the text of the organisation's public profile page.

## What is inside

- `profile/README.md`: the organisation landing page and the map of its repositories.
- `CODE_OF_CONDUCT.md`: the Contributor Covenant 2.1, with enforcement reports sent to data@one.org.
- `SECURITY.md`: how to report a vulnerability privately.
- `SUPPORT.md`: where to take bugs, feature requests and data questions.
- `.github/ISSUE_TEMPLATE/`: issue forms for bug reports and feature requests, and the contact links shown on the new-issue page.
- `.github/pull_request_template.md`: the default pull request description.
- `LICENSE`: MIT.

## How the defaults work

GitHub applies a file in this repository to every public repository in the organisation that has no file of its own of the same kind. A repository that has its own `.github/ISSUE_TEMPLATE/` directory or its own pull request template keeps it, and the default is not merged in. Edits here take effect on `main`.
