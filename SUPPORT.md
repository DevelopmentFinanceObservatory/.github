# Support

Where to take a question depends on what it is about.

- For a bug or feature request, open an issue in the repository concerned. The [repository list](https://github.com/DevelopmentFinanceObservatory) shows what each one holds.
- For data, research and partnership questions, write to [data@one.org](mailto:data@one.org).
- For a security vulnerability, follow the [security policy](SECURITY.md) and report it privately.

Contributors are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
